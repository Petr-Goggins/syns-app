# Реализация разминки и заминки для новичков

## Обзор изменений

В рамках задачи по добавлению разминки и заминки в программу тренировок для новичков были внесены следующие изменения:

## Созданные файлы

### 1. `/src/data/warmup.ts` (новый файл)
Содержит:
- **Интерфейс `WarmupExercise`** — тип данных для упражнений разминки/заминки
- **Массив `warmupExercises`** — 10 упражнений для разминки:
  - Лёгкое кардио (2-3 минуты)
  - Вращения головой, плечами, кистями
  - Махи руками
  - Наклоны корпуса
  - Вращения тазом
  - Приседания без веса
  - Вращения коленями и голеностопом
  
- **Массив `cooldownExercises`** — 8 упражнений для заминки:
  - Растяжка квадрицепсов
  - Растяжка hamstring
  - Растяжка грудных мышц, плеч, трицепса
  - Растяжка спины (поза ребёнка)
  - Растяжка шеи
  - Глубокое дыхание
  
- **Массив `safetyGuidelines`** — 7 правил техники безопасности:
  - Начинайте с малых весов
  - Следите за дыханием
  - Если чувствуете боль — остановитесь
  - Пейте воду во время тренировки
  - Разминайтесь перед тренировкой
  - Делайте заминку после тренировки
  - Слушайте своё тело

- **Вспомогательные функции**:
  - `getRandomWarmup(count)` — случайные упражнения разминки
  - `getRandomCooldown(count)` — случайные упражнения заминки
  - `getAllWarmupExercises()` — все упражнения разминки
  - `getAllCooldownExercises()` — все упражнения заминки

#### Новый UI для новичков:

1. **Расширенный блок безопасности** с кнопкой "Подробнее":
   - 4 основных правила видны сразу
   - Дополнительные 3 правила открываются по клику

2. **Две отдельные карточки**:
   - 🔥 **Разминка (5-7 минут)** — красный градиент
     - Краткий список из 5 упражнений
     - Кнопка "Все упражнения" показывает все 10
   
   - 🧘 **Заминка (5-10 минут)** — синий градиент

3. **Отображение дней тренировки**:
   - Для новичков: три секции (разминка, основная, заминка)
   - Для опытных: только основная тренировка
   - Каждая секция визуально выделена цветом

## Как это работает

### Для новичков:
1. При создании плана автоматически добавляются:
   - Блок техники безопасности
   - Карточки с разминкой и заминкой
   - Структурированные дни тренировок с тремя секциями

2. Пользователь может:
   - Развернуть дополнительные рекомендации по безопасности
   - Показать все упражнения разминки/заминки
   - Видеть чёткое разделение на секции в каждом дне

### Для опытных пользователей:
- Отображается только основная тренировка
- Нет дополнительных блоков (чтобы не перегружать интерфейс)
