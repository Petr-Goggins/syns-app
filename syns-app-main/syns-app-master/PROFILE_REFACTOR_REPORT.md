## 📋 Выполненные задачи

### 1. Созданные файлы

#### `/src/lib/waterNorm.ts`
- Функция `calculateWaterNorm(weight, activityLevel)` — расчёт нормы воды по формуле: вес × 30 мл × коэффициент активности
- Функция `formatWaterNorm(ml)` — форматирование значения (мл или л)
- Коэффициенты активности:
  - `sedentary` (сидячий): 1.0
  - `light` (лёгкая): 1.1
  - `moderate` (средняя): 1.2
  - `active` (высокая): 1.3
  - `very_active` (очень высокая): 1.4

- Универсальный компонент календаря в стиле GitHub
- Пропсы: `data`, `title`, `icon`
- Сетка 7×N дней с цветовой индикацией
- Hover-эффект (scale 110%)
- Всплывающие подсказки с датой и деталями

## 🔧 Как это работает

### Тепловая карта мышц
```typescript
// MuscleHeatmap.tsx загружает workout_logs за 7 дней
// Для каждого упражнения определяется мышца через muscleMapping
// Нагрузка = weight × sets × reps (или просто счётчик если нет весов)
// Интенсивность нормализуется от 0 до 3
```

### Календари
```typescript
// Каждый день за последние 30 дней проверяется в БД
// Питание: суммируются белки/жиры/углеводы, считаются отклонения
// Тренировки: проверка наличия записи в workout_logs
// Цвет сохраняется в объекте дня для оптимизации рендера
```

### Норма воды
```typescript
// Формула: weight (кг) × 30 (мл) × coefficient (активность)
// Пример: 75 кг × 30 × 1.2 (moderate) = 2700 мл = 2.7 л
```
